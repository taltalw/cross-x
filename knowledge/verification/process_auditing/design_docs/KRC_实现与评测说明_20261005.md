# KRC：实现、离线评测与结果分析

日期：2026-10-05。状态：代码与脚本已实现，3方案冒烟测试及21方案小样本计算已完成。

## 1. 本次执行口径

遵照最新要求：**只评测保存了Embedding分数的需求—候选配对**。复用原KNC的同一批21个方案，原子样本不变，仍为7个源原子样本各自的双域、三域、四域方案。

从126项需求与保留材料形成的1260个配对中：

- 611个有Embedding分数：全部纳入Cosine-only条件KRC，覆盖126项需求。
- 其中215个同时有BM25分数：纳入BM25+Cosine混合条件KRC，覆盖90项需求。
- 其余396个只有Embedding分数：参与Cosine-only，混合模式排除。
- 没有Embedding分数的649个配对：不参与任何模式的评分，仅计入范围审计总数。

本次对“Embedding有分、BM25缺失”的处理采用已说明的默认方案：分别报告Embedding可用集和双路齐全集，不补零，不临时重分配方法权重。这避免把缺失BM25当成真实低分。

计算全程使用本地已有JSONL，不调用Embedding模型、LLM、API或向量库。RRF保持原候选排序作用，不作为第三路加权分数。

## 2. 相比原设计的变化

旧设计让全部需求进入分母，并将缺失分数作为可观察贡献下界0；最新要求改为只评价有分数的部分。

因此当前KRC是 **observed-score conditional KRC，即有分数子集上的条件知识需求覆盖率**。

| 情况 | 当前处理 |
|---|---|
| 配对没有Embedding | 不评分 |
| 配对只有Embedding | Cosine模式评分；双路模式排除 |
| 配对两路齐全 | 可计算Cosine、BM25、混合分数 |
| 分数真实为0或负Cosine | 仍属于有分数配对；负Cosine按约定clip为0 |
| 需求没有当前模式可用候选 | weight=null，covered=null，排除出该模式条件分母 |
| 新增领域没有有效需求 | 该领域均值null；方案按有有效需求的新增领域平均，报告领域纳入数 |
| 方案没有任何有效需求 | 方案不可评测，不记零分 |
| 七个源领域缺少可评测组 | 完整宏平均N/A；局部均值单独保留 |

当前不报告旧版缺失分数保守上下界，因为评测对象已经明确限制在有分数的配对。缺失仍通过配对、需求、领域、方案纳入数量呈现。

## 3. 当前实现的公式

需求i属于目标领域d。先按原候选顺序取预算K，再定义：

\[
C_i^E=\{c:\text{该配对有Embedding分数}\},\qquad
C_i^{BE}=\{c:\text{该配对同时有BM25和Embedding分数}\}.
\]

Cosine截断为e_ic^norm=clip(e_ic,0,1)。BM25使用固定参考集范围：

\[
b_{ic}^{norm}=\operatorname{clip}\left(\frac{b_{ic}-L_d}{U_d-L_d},0,1\right).
\]

不会按每项需求自己的候选重新做Min-Max，以免每项需求的最大BM25分数都变成1。

四种输出模式：

| 代码模式 | 有效候选集合 | 逐需求权重 |
|---|---|---|
| cosine_observed | C_i^E | max_c e_ic^norm |
| hybrid_complete | C_i^BE | max_c [0.5 b_ic^norm + 0.5 e_ic^norm] |
| cosine_complete | C_i^BE | max_c e_ic^norm |
| bm25_complete | C_i^BE | max_c b_ic^norm |

后三种使用完全相同的候选支持集，便于比较分数组成。混合模式必须先在同一材料上加权，再取最大值，不能把不同材料的两种最高分拼起来。

对于模式M和目标领域d，令I_d^M为至少有一个有效候选的需求集合：

\[
\boxed{KRC_{Binary,d}^M(\tau)=\frac{1}{|I_d^M|}\sum_{i\in I_d^M}\mathbb1[w_i^M\ge\tau]},
\]

\[
\boxed{KRC_{Weighted,d}^M=\frac{1}{|I_d^M|}\sum_{i\in I_d^M}w_i^M}.
\]

I为空时两个值均为null。**分母是有效需求数，不是材料数或配对数。** Weighted不再按阈值截断，也不受τ影响。

对每个方案，等权平均有有效需求的新增领域；再依次等权平均同源方案、七个源领域。k=2/3/4分开计算。领域、方案、源领域的排除计数均保留。

因此结果表里的宏平均通常不等于“所有达标需求数÷所有纳入需求数”。本次混合四域@0.50有一项需求达标，但1.59%是分层宏平均，不是1/43。

## 6. 如何解读这些数值

- **Weighted提供了比高阈值下几乎全零的Binary更多的信息。** Cosine-only约0.23–0.24，混合约0.24–0.26；它们是归一化匹配强度，不是支持概率、准确率或答案质量分数。
- **阈值影响很大。** 混合@0.20的双/三/四域宏平均为76.19%、64.29%、87.30%；@0.30降为19.05%、15.48%、20.63%；@0.50为0%、0%、1.59%。不能为了提高覆盖率而选择低阈值。
- **四域略高不证明四域知识质量更好。** 样本只有7个共享原子，且不同模式支持集不同，不能据此得出总体或因果结论。
- **混合值提高部分来自分数尺度。** 本次双路集的BM25归一化最佳分数均值高于Cosine；这不能直接证明BM25更准确。
- **缺失配对按要求排除，但选择偏差仍存在。** 当前结论仅适用于保存分数的材料，不包括649个没有Embedding记录的配对。

唯一在混合@0.50下达标的需求来自 mathematics 源领域的四域方案，目标medical，第2项需求文本为 `Pregnancy influenza risk and inactivated vaccination`。最佳材料的分数为：

- BM25原始分数18.553891271962136，超过medical参考最大值18.151740249165872，按既定规则clip为1。
- Cosine为0.3109332025051117。
- 混合权重为0.5×1+0.5×0.3109332025051117=0.6554666012525558。

这项命中受到强词项匹配及固定归一化范围影响；这里只复现检索记录，不验证其医学内容或知识充分性。
