**关于你最关心的领域分布熵，我建议这样定义。**

设：

- 全部领域集合为 \(\mathcal D\)，领域数为 \(m\)，当前 \(m=7\)。
- 样本 \(i\) 的源领域为 \(a_i\)。
- 完整参与领域集合为 \(S_i\)，领域数 \(k=|S_i|\)。
- 新增领域集合为 \(B_i=S_i\setminus\{a_i\}\)，因此 \(|B_i|=k-1\)。

这里的 \(k\) 始终包含源领域，与你当前 `domain_count` 一致。

对于固定源领域 \(a\) 和固定领域数 \(k\)，所有可能的新增领域组合为：

\[
\Omega_{a,k}
=
\{T\subseteq\mathcal D\setminus\{a\}:|T|=k-1\}
\]

其数量为：

\[
|\Omega_{a,k}|=\binom{m-1}{k-1}
\]

定义组合 \(T\) 的经验概率：

\[
\pi_{a,k}(T)
=
\frac{
\#\{i:a_i=a,\ |S_i|=k,\ B_i=T\}
}{
N_{a,k}
}
\]

其中 \(N_{a,k}\) 是该分组的方案数。推荐主指标为**归一化领域组合熵**：

\[
\boxed{
H_{\mathrm{comb}}(a,k)
=
-\frac{
\displaystyle\sum_{T\in\Omega_{a,k}}
\pi_{a,k}(T)\log\pi_{a,k}(T)
}{
\displaystyle\log\binom{m-1}{k-1}
}
}
\]

约定 \(0\log0=0\)。

它自然兼容不同领域数：

| 总领域数 | 固定源领域后需要选择 | 当前可选组合数 | 归一化分母 |
|---|---|---:|---|
| \(k=2\) | 一个新增领域 | 6 | \(\log6\) |
| \(k=3\) | 两个新增领域 | 15 | \(\log15\) |
| \(k=4\) | 三个新增领域 | 20 | \(\log20\) |

解释也比较直接：

- \(H_{\mathrm{comb}}=0\)：始终选择同一种组合。
- \(H_{\mathrm{comb}}=1\)：所有可选组合等频出现。
- 中间值：反映组合覆盖与均衡程度。

对七个源领域做等权宏平均：

\[
\boxed{
\mathrm{DDE}_k
=
\frac{1}{m}
\sum_{a\in\mathcal D}H_{\mathrm{comb}}(a,k)
}
\]

**这就是我建议放进 PPT 的主要公式。** 报告 \(\mathrm{DDE}_2,\mathrm{DDE}_3,\mathrm{DDE}_4\)，避免先混合不同领域数再计算一个熵。若必须给总体值，可以再对这三个结果等权平均。

这里采用标准 Shannon 熵及固定支持集归一化；指标在本任务中的统计对象和分层方式，是针对你的 pipeline 提出的设计。若需要更直观的补充量，可以报告 \(\exp(H_{\mathrm{raw}})\)，解释为“有效组合数”。熵转为有效类别数的解释可参考 [Jost, 2006](https://pdodds.w3.uvm.edu/research/papers/others/2006/jost2006a.pdf)。

计算时有几个边界需要固定：

- 分母使用**全部预先定义的组合数**，不能使用“实际出现的组合数”，否则只覆盖很少组合也可能得到满分。
- 同一方案的 easy/medium/hard 在领域选择评测中只算一次。
- 某分组没有样本，或只有一个可能组合时，标记为不适用，并单独报告覆盖情况。
- 对比方法时保持源样本和样本量一致；归一化并不能消除小样本估计偏差。
- 高熵只表示覆盖均衡，**不证明这些组合自然、合理或必要**。

你的原始单领域熵仍然有用，但应作为辅助指标。对于固定 \(a,k\)，正确的概率应为：

\[
p_{a,k}(d)
=
\frac{
\#\{i:a_i=a,\ |S_i|=k,\ d\in B_i\}
}{
N_{a,k}(k-1)
}
\]

这样才有 \(\sum_{d\ne a}p_{a,k}(d)=1\)，从而：

\[
H_{\mathrm{domain}}(a,k)
=
-\frac{\sum_{d\ne a}p_{a,k}(d)\log p_{a,k}(d)}
{\log(m-1)}
\]

**不能直接把“某领域出现在多少比例的样本中”作为多领域熵的概率。** 三域时，这些出现比例之和是 2；四域时是 3。

另外，即使每次都选择同一个新增领域集合，单领域熵也会随着集合大小增加而上升。因此，你当前数据中 0.634 → 0.866 的变化，不能直接解释为多样性提升。

针对“数学是否被过度选择”，更适合另外报告：

\[
\mathrm{SelectRate}_k(d)
=
\frac{
\#\{i:|S_i|=k,\ a_i\ne d,\ d\in B_i\}
}{
\#\{i:|S_i|=k,\ a_i\ne d\}
}
\]

它排除了“该领域本来就是源领域”的样本。在均匀随机选择的参照下，这个比例为 \((k-1)/(m-1)\)；这只是描述性基线，不能当作自然融合的目标分布。

**每一步的指标，建议围绕“这一阶段应该保证什么”来设计。**

下面按 PPT 的五个阶段组织；当前代码中领域选择与思路生成合在一起，评测时仍可拆开。

| 阶段 | 核心指标 | 操作性定义／评测方式 |
|---|---|---|
| 前置：原子样本 | 源知识可靠率 | 抽查实际参与生成的知识，判断答案、关键事实和领域归属是否正确 |
| ① 可融合领域选择 | **组合可行率** | 所选领域能否围绕源样本形成自然的共同任务；允许判断“不适合融合” |
| ① 可融合领域选择 | **组合熵＋领域选择率** | 使用上述公式，分别在候选方案和最终验收集合上计算 |
| ② 融合思路生成 | **真正整合通过率** | 是否存在有实质作用的跨域推理依赖，而非几个独立问题共享一个故事 |
| ② 融合思路生成 | 源知识保留率 | 源样本核心知识是否仍在最终任务中承担必要作用 |
| ③ 知识需求生成 | **需求完备率＋需求有效率** | 必要知识有没有漏写；提出的需求是否具体、必要、可检索，且不是同义重复 |
| ④ 检索与过滤 | **原始需求覆盖率＋证据支持精度** | 材料是否支持检索前提出的需求；被保留材料是否真正提供有效证据 |
| ⑤ 融合样本生成 | **答案有效率＋跨域必要性** | 答案正确唯一、证据充分、各领域必要、领域间关系成立 |
| 最终验收 | **联合通过率＋捷径检查** | 同时通过上述关键要求，并通过位置、选项、泄漏和重复检查 |

其中几个指标需要更明确地落地。

**融合思路的评测，应要求提供可核查的推理依赖。** 每个领域至少标注一个必要知识节点，以及它如何影响后续推理或共同决策。单纯把三个答案拼成一句话，不算跨域依赖。

例如，你 20260923.pptx（原工作区来源，未随包提供：`/home/zhangpengyue/benchmark/20260923.pptx`） 中标记为“√”的“识别气体，再计算浓度降至初始值 1% 的时间”，在给定通风模型下：

\[
t=\frac{V}{Q}\log100
\]

时间不依赖气体身份。因此，这个例子可能仍是化学识别与数学计算的并列。若要形成依赖，需要让前一步识别结果决定后一步有依据的参数、模型或适用条件。

这类检查与 MuSiQue 要求“一步推理必须依赖另一步提供的信息”的设计思路一致；但你还需要额外检查领域标签与知识贡献。[MuSiQue, 2022](https://aclanthology.org/2022.tacl-1.31/)

**知识需求可以用一个小规模人工参考集评测。** 对抽样方案，由审查者列出所需的必要知识集合 \(G_i\)，再与生成需求 \(R_i\) 做语义匹配：

\[
\mathrm{ReqRecall}_i
=
\frac{\text{被生成需求覆盖的必要知识数}}{|G_i|}
\]

\[
\mathrm{ReqPrecision}_i
=
\frac{\text{必要且表述有效的生成需求数}}{|R_i|}
\]

先合并同义需求，避免把一个知识点拆成三句话提高分数。原子样本的清洗范围也可以据此控制：重点审查最终使用的知识及其来源，无需把整个原始语料全部清洗完成才开始评测。

**检索阶段应建立“需求—证据”对应关系。** 对每个必要需求标记：

- 充分支持；
- 部分支持；
- 不支持；
- 与材料矛盾。

主指标采用严格口径：

\[
\mathrm{NeedCoverage}_i
=
\frac{\text{获得充分证据支持的必要需求数}}
{\text{必要需求总数}}
\]

同时报告：

\[
\mathrm{AllNeedsSupported}
=
\frac{\text{全部必要需求均获充分支持的方案数}}
{\text{被评测方案数}}
\]

均值覆盖率可能掩盖一个致命知识缺口，因此这两个指标需要一起报告。还可以补充各领域覆盖率的最小值，暴露多域任务中的薄弱领域。

**你 PPT 中的 SNR，建议改名并拆分。**

“最终答案使用的材料数／保留材料数”，实际上更接近**材料利用率**：

\[
\mathrm{Utilization}
=
\frac{\text{经独立核查、实际支持有效解答的材料数}}
{\text{交给生成器的保留材料数}}
\]

它不能单独证明模型是否依赖先验知识：

- 利用率低，可能只是检索了多份重复证据。
- 利用率高，也可能是解释中强行引用材料。
- 材料被引用，不代表材料支持结论，更不代表缺少材料就无法答题。

因此建议拆成：

| 指标 | 回答的问题 |
|---|---|
| 需求覆盖率 | 需要的知识找齐了吗？ |
| 证据支持精度 | 保留的材料中，有多少真正支持必要知识？ |
| 材料利用率 | 交给生成器的材料中，有多少进入了有效解答？ |
| 最终知识主张支持率 | 最终解答中的领域知识，有多少得到来源支持？ |

最后一项应区分“领域知识”和“题目合法设定的条件”。虚构一个工厂场景本身不必然不合格；需要拦截的是无依据的专业事实、矛盾设定，以及为了凑领域而添加的无作用情节。

**当前 v4 还必须加入“原始需求与修订需求”的区分。**

代码会先筛选材料，再改写 `question_plan` 和 `required_key_facts`。这一行为见 生成阶段实现（原工作区来源，未随包提供：`/home/zhangpengyue/benchmark/cross-x/knowledge/pipielines_v4/4_generate_fusion_question.py:313`）。

因此应分别计算：

\[
C_{\mathrm{original}}
=
\mathrm{Coverage}(\text{原始需求},\text{检索材料})
\]

\[
C_{\mathrm{revised}}
=
\mathrm{Coverage}(\text{修订需求},\text{选中材料})
\]

前者评价需求驱动检索是否成功；后者评价修订后的任务是否有依据。再人工判断修订属于措辞调整、合理收缩，还是任务实质改变。

不能只用 \(C_{\mathrm{revised}}\) 证明原始 pipeline 成功，否则“没找到所需知识，于是换一个问题”也会被算成检索成功。当前最终输出的方案文本均与最初方案不同，但**文本不同不等于实质换题**，仍需语义审查。

**跨域必要性建议同时做结构审查与消融实验。**

先做结构审查：对每个领域提出两个问题。

- 缺少该领域的关键知识，目标答案是否仍然可以由其他信息确定？
- 改变该领域相关的有效输入，是否会经由合理的推理关系影响共同结论？

这里要检查实际题目和选项。你当前一个三域化学样本的四个选项都把气体写为 phosphine，意味着化学识别结果对区分选项没有作用；即使解释提到了化学，也不足以证明化学知识必要。参见 该样本（原工作区来源，未随包提供：`/home/zhangpengyue/benchmark/cross-x/knowledge/pipielines_v4/outputs/4_generate_fusion_question/chemistry/test_domain_count_3.jsonl:1`）。

对于行为消融，设样本 \(i\) 的完整领域集合为 \(S_i\)，\(A_i(T)\) 表示固定探测模型仅获得领域集合 \(T\) 对应证据时的正确率。建议将原来的 IG 改称**最佳子集增益**：

\[
\boxed{
\mathrm{BSG}_i
=
A_i(S_i)
-
\max_{T\subsetneq S_i}A_i(T)
}
\]

在固定 \(k\) 的样本上取平均：

\[
\mathrm{BSG}_k
=
\frac{1}{N_k}\sum_{i:|S_i|=k}\mathrm{BSG}_i
\]

注意先逐题找最佳子集，再平均；只在总体准确率上找一个最佳子集，可能漏掉“每题冗余的领域不同”的情况。

包括空证据条件时，双域、三域、四域分别只有 **4、8、16 种证据条件**，可以在抽样审计集上枚举。成本受限时，使用逐域移除：

\[
\Delta_{i,d}
=
A_i(S_i)-A_i(S_i\setminus\{d\})
\]

\[
\mathrm{LODO}_i^{\min}
=
\min_{d\in S_i}\Delta_{i,d}
\]

它衡量最容易被省略的领域所带来的增益。但模型表现不一定随证据增加而单调变化，因此逐域移除不能自动替代全部子集实验。

实验解释上必须保留三个限制：

- **删除证据不会删除模型已有的领域知识。** 该实验测的是外部证据依赖。
- **单领域微调模型也可能保留其他领域知识。** 它不能等价于“只知道一个领域”。
- 完整条件和子集条件都答错，不能证明该领域冗余；应同时报告完整条件正确率。

证据应整理成事实卡片，避免直接包含最终答案或解释。正确率来自预先固定的重复作答或探测协议，不能把一次回答当作精确概率。**所有领域都必要，也仍不保证真正整合**：几个独立子问题的联合评分同样可能表现出逐域移除损失，所以结构审查不能省略。

最终验收应采用关键条件的联合门槛，不能让高多样性抵消错误答案。同时保留逐项失败标签：

| 失败原因 | 优先回退位置 |
|---|---|
| 所选领域无法形成自然共同任务 | 领域选择／融合思路 |
| 思路合理，但缺失关键需求 | 知识需求生成 |
| 需求合理，但未找到证据 | 检索；语料无支持则舍弃或明确修订 |
| 证据充分，但答案错误或不唯一 | 样本生成 |
| 某领域可省略，或只有知识并列 | 融合思路 |
| 选项位置、措辞或格式泄漏 | 选项构造与最终验收 |

回退后保留旧版本和失败原因，设置有限重试次数，统计成本。

对于 **Model Merging**，主实验应固定输入协议。例如闭卷主评测只给题目和选项；提供证据的实验单独报告，避免把专业知识迁移与材料阅读混在一起。

至少比较基础模型、各单域专家和融合模型，并固定相同的测试题。推荐四项主要结果：

\[
\mathrm{Gain}_{\mathrm{base}}
=
\mathrm{Acc}(M_{\mathrm{merge}})
-
\mathrm{Acc}(M_{\mathrm{base}})
\]

\[
\mathrm{Gain}_{\mathrm{expert}}(S)
=
\mathrm{Acc}_{S}(M_{\mathrm{merge}})
-
\max_{d\in S}\mathrm{Acc}_{S}(M_d)
\]

\[
\mathrm{UniqueSolve}(S)
=
\frac{
\#\{\text{融合模型答对，且所有参与域专家均答错的题}\}
}{
N_S
}
\]

\[
\Delta_{\mathrm{atomic}}
=
\frac1m\sum_d
\left[
\mathrm{Acc}_{d}(M_{\mathrm{merge}})
-
\mathrm{Acc}_{d}(M_d)
\right]
\]

分别回答：

- 是否超过基础模型？
- 是否超过该组合上的最佳单域专家？
- 是否出现单个专家均未解决、融合模型解决的题？
- 跨域收益是否伴随单域能力退化？

对 `UniqueSolve` 同时报告反向情况：至少一个专家答对、融合模型却答错的比例，避免只统计收益。

错误分析可以沿用 PPT 的三类，但需要增加可验证依据：

| 错误类别 | 推荐判据 |
|---|---|
| 领域知识缺失 | 对应必要知识的独立探针题答错 |
| 知识并列、未完成整合 | 相关知识探针答对，但没有应用必要的跨域关系 |
| 领域关系错误 | 相关知识探针答对，但关系应用、条件传递或共同决策出错 |

这些探针应来自最终任务的必要知识节点，而非直接复用可能已偏离最终任务的原始题。可借鉴多跳问答中联合检查整体问题与子问题的评测思路。[Tang et al., 2021](https://aclanthology.org/2021.eacl-main.283/)

**不能仅凭模型选择了某类干扰项，就确定其内部失败原因。** 干扰项类型可用于输出行为统计；原因归属需要探针或进一步审查，无法确定时保留“混合／未知”。

---

落地时，我建议先建立一个**按源领域、领域数分层的审计集**：例如每个“源领域×领域数”抽 10 个方案，共 210 个方案，审查其全部难度版本；同时覆盖少见组合和被筛除方案。这个规模适合校准规则，不足以精确估计每个稀有组合的质量。

执行顺序可以是：

- 独立审查者先不看生成器的解释，判断答案、必要知识和跨域关系，再核对解释与引用。
- 双人独立标注一部分，处理分歧后固定评测准则；LLM 评审器用这部分标注校准。
- 在独立模型测试前，随机置换选项并同步标签；报告置换后按答案内容衡量的一致性、仅看选项的作答结果及多数标签基线。
- 按源样本及共享证据关系控制数据划分，检查与专家训练数据的精确和近似重复。
- 按领域数、领域组合、源领域和难度分层报告结果；置信区间至少按源样本聚类，避免把三个难度版本当作独立样本。
- 做同源样本、同预算的 pipeline 消融：随机领域选择、去掉需求驱动检索、去掉证据过滤、去掉独立验收，比较合格产出率、成本和最终覆盖。

这样，你的 PPT 可以保留一组清晰的主指标：**组合可行率与组合熵 → 真正整合通过率 → 需求完备率 → 原始需求覆盖率 → 答案有效率与跨域必要性 → 合格产出率与模型融合增益**。每项都有独立含义，也能定位失败应该回退到哪一步。
