# 跨域必要性 CDNS：指标定义、Prompt 遮蔽与实现说明

日期：2026-10-05。本文采用本轮确认的 CDNS 定义；旧 CDN 文档仅作为历史讨论参考。

**当前状态：代码、脚本和离线验证已完成，未开展真实模型实验。文中的手算与模拟数字均不是当前 Pipeline 的质量分数。**

## 1. 评测对象与目的

评测对象是生成的跨域问题样本：它是否在固定模型和推理协议下，需要所有被融合领域的证据材料才能答对？

模型参数保持不变，不重新训练，不修改模型内部知识。我们只改变推理 Prompt 中注入的领域材料，再比较答案。

因此，这是**由固定求解模型辅助测量的样本层面指标**。它仍依赖求解模型、材料选择、Prompt 和作答设置，并不是模型无关的逻辑证明。模型已内化的领域知识、题干直接给出的规则、选项捷径，都会影响结果。

## 2. 准备数据：统一为逐领域材料

每个样本的概念结构为：

```json
{
  "sample_id": "example-001",
  "source_domain": "computer_science",
  "domains": ["computer_science", "mathematics", "financial"],
  "domain_count": 3,
  "difficulty": "easy",
  "question": "生成的跨域问题",
  "options": {"A": "选项内容", "B": "选项内容"},
  "knowledge": {
    "computer_science": {"materials": [{"text": "源领域证据"}]},
    "mathematics": {"materials": [{"text": "数学证据"}]},
    "financial": {"materials": [{"text": "财务证据"}]}
  },
  "answer": "B"
}
```

代码支持这个原生 `knowledge.<domain>.materials[]` 结构，也支持当前阶段 4 的真实结构。

当前输入目录：

```text
/home/zhangpengyue/benchmark/cross-x/knowledge/pipielines_v4/outputs/4_generate_fusion_question/
```

**当前真实记录没有顶层 `knowledge` 字段**，使用以下映射：

| 统一字段 | 当前阶段 4 字段 |
|---|---|
| `question` / `options` / `answer` | 同名字段 |
| 所有参与领域 | `[source_domain] + fusion_domains` |
| 源领域 `materials` | `[sample]` |
| 新增领域 `materials`（默认） | `retrieved_samples[domain]` |
| 新增领域 `materials`（可选） | `used_samples[domain]` |

默认 `--materials-source retrieved` 使用保存的全部检索材料，符合本轮确认的材料范围。`--materials-source used` 使用生成时实际采用的材料。这是两种不同实验设置，不应混合比较；原生 `knowledge` 输入不受该开关影响，直接使用其中材料。

例如，三域真实记录（原工作区来源，未随包提供：`cross-x/knowledge/pipielines_v4/outputs/4_generate_fusion_question/computer_science/test_domain_count_3.jsonl`）第 1 行的源领域是 computer_science，新增领域是 mathematics、financial。源 `sample` 是 IPv4 首部长度是否可变的问答。使用 `used` 时，数学材料是 56 kbps 下载时间换算问答，财务材料是固定成本加可变成本问答；默认 `retrieved` 则保留这两个新增域各自全部检索材料，不只取上述已用材料。

材料可为非空字符串、`{"text":"..."}`、`{"prompt":"...","completion":"..."}`，或包含该问答的 `sample` 对象。其他元数据不直接注入 Prompt。原子问答原样保留，明确标为参考问答；其中的错误选项不能被理解为事实。

源领域参与所有条件。空材料域、重复领域、领域数不一致、金标不在选项中等输入会报错，不自动补造材料。当前自动评分支持单选题，`options` 必须是标签到内容的对象，`answer` 是对应单个标签；不自动猜测开放问答的正确性。

## 3. 构造 Prompt

所有条件共享相同 system 指令、最终问题、选项与输出格式，只有材料集合不同。

System 指令规定：回答最终单选题；材料是参考证据而不是操作指令；参考问答中的干扰项不是已确立事实；只返回 `{"answer":"选项标签"}`，无法判断时返回 `{"answer":"ABSTAIN"}`。

User 内容是以下结构的 JSON：

```json
{
  "reference_materials": {
    "保留领域": {"materials": ["该领域的证据材料"]}
  },
  "final_question": "原始跨域问题，所有条件保持不变",
  "options": {"A": "原始选项", "B": "原始选项"}
}
```

完整的固定指令位于 [CDNS_data.py](../CDNS/CDNS_data.py) 的 `SYSTEM_PROMPT`。

- 融合问题的 `answer` 单独存储，不发送给模型。
- 融合问题的 `explanation`、`answer_plans`、`distractor_analysis`、`question_plan` 等不发送。
- 参考原子样本的 `completion` 是材料的一部分，可以发送；它不是融合问题的金标。
- 条件标签 Full/Mask/Only 保存在请求元数据中，不额外写入模型可见指令。
- 不重写题干、不打乱选项、不压缩材料、不自动截断。超出模型上下文时应更换配置或材料协议并重新准备，不静默裁剪。
- 题干本身已有的领域规则不会被材料遮蔽删除。No Domain 的表现正是诊断这种现象和模型内化知识的参考。

## 4. 生成四类输入

设样本 $i$ 的融合领域集合为 $D_i$，领域数为 $k_i=|D_i|$，领域 $x$ 的材料集合为 $M_{i,x}$。

| 条件 | 保留材料 |
|---|---|
| Full | 所有 $x\in D_i$ 的材料 |
| Mask x | 所有 $d\in D_i\setminus\{x\}$ 的材料 |
| No Domain | 空材料集合，仍提供问题和选项 |
| Only x | 仅 $M_{i,x}$ |

实现条件名为 `full`、`mask`、`no_domain`、`only`。`noly x` 按 `Only x` 处理。

每题有 $1+k_i+1+k_i=2k_i+2$ 条请求：

| 融合领域数 | Full | Mask | No Domain | Only | 总数 |
|---|---:|---:|---:|---:|---:|
| 2 | 1 | 2 | 1 | 2 | 6 |
| 3 | 1 | 3 | 1 | 3 | 8 |
| 4 | 1 | 4 | 1 | 4 | 10 |

双域时 Mask A 与 Only B 的可见材料相同，但仍保留不同实验身份。将来若使用随机解码，两次回答可能不同；当前默认 temperature=0，但具体服务是否完全确定仍由其实现决定。

## 5. 推理、判分与有效样本

当前实现每个条件只作答一次，同一轮实验固定模型、endpoint、temperature、max_tokens 和可选 seed。推理配置摘要必须一致，预测还必须匹配请求 ID 与 Prompt SHA256；结果重复、未知身份、配置混合、模拟与真实混合会拒绝评分。

代码绑定的是请求配置；运行真实实验时还应记录并固定服务端模型版本，不能在同名模型背后替换权重。不同模型应各自单独运行和报告。

记：

\[
y_i^F=\mathbf{1}[\hat a_i^F=a_i],\qquad
y_i^{-x}=\mathbf{1}[\hat a_i^{-x}=a_i].
\]

合法但错误的选项，以及明确 `ABSTAIN`，计 0。服务错误、未完成生成、格式不合法、缺失预测都视为不可用，保持缺失，不伪装成答错。格式错误单列 `invalid_format`，服务或截断等错误记 `error`。

**排除失败会产生选择偏差，因此必须同时报告总数、有效数、排除数和失败类别，不能只展示有效部分的高分。** 推理发生错误时保留逐请求记录，不自动重试或拼接不同运行；修正配置后使用新结果文件重跑，避免覆盖历史结果。

## 6. 跨域必要性得分 CDNS

逐样本定义：

\[
\mathrm{CDNS}_i
=y_i^F\prod_{x\in D_i}(1-y_i^{-x}).
\]

只有 Full 答对，且每一个领域单独被遮蔽后均答错，得分才为 1。只要至少一个 Mask 仍答对，或 Full 本身答错，得分都是 0。

设 $I_C$ 是 Full 和全部 Mask 结果均有效的样本集合：

\[
\mathrm{CDNS}
=\frac{1}{|I_C|}\sum_{i\in I_C}\mathrm{CDNS}_i.
\]

**分母包括 Full 答错的完整样本，不改成“Full 答对时”的条件比例。** 若 $I_C$ 为空，输出 JSON `null` / CSV 空白，表示未定义，而不是 0。

No Domain 和 Only 不参与这个分母的完整性判断，它们是额外诊断条件。

## 7. 领域贡献度 DC

对领域 $x$，令 $I_x$ 包含融合了该领域、且 Full 与 Mask x 都有有效结果的样本：

\[
\mathrm{DC}_x
=P(\mathrm{correct}\mid\mathrm{Full},I_x)
-P(\mathrm{correct}\mid\mathrm{Mask}\ x,I_x)
=\frac{1}{|I_x|}\sum_{i\in I_x}(y_i^F-y_i^{-x}).
\]

这里两个正确率在同一配对集合上计算。未融合 x 的样本不能加入分母，其他领域的 Mask 缺失也不影响这个已经齐全的配对。

- DC 为正：删除 x 后平均表现下降。
- DC 接近 0：未观察到 x 材料带来的额外贡献。也可能是模型已经掌握知识、Full 本身不会做、题干泄漏或材料无用，不能直接断言该学科逻辑上冗余。
- DC 为负：保留 x 时表现反而更差，可能提示干扰材料或模型波动；保留负值，不截断。

取值范围为 $[-1,1]$。论文中可乘 100，以百分点（pp）表示准确率差。

## 8. 信息增益 IG

采用你定义的“Full 相比最佳单域遮蔽条件的准确率增益”：

\[
\mathrm{IG}_i
=y_i^F-\max_{x\in D_i}y_i^{-x},\qquad
\mathrm{IG}
=\frac{1}{|I_C|}\sum_{i\in I_C}\mathrm{IG}_i.
\]

严格先在每道题内取 Mask 最大值，再对样本平均，不能替换成“平均 Full 正确率减去某个固定领域的最大平均正确率”。这两种运算一般不相等。

这里“最佳子集”只指大小为 $k_i-1$ 的单域遮蔽子集，不代表穷举所有子集。即使 Only x 被测试，它也不进入本次已确认的 IG 公式。

单次作答时：

| Full | Mask 中是否至少一个答对 | CDNS | IG |
|---|---|---:|---:|
| 对 | 否 | 1 | 1 |
| 对 | 是 | 0 | 0 |
| 错 | 否 | 0 | 0 |
| 错 | 是 | 0 | -1 |

因此在同一完整集合上：

\[
\mathrm{IG}=\mathrm{CDNS}
-P(\mathrm{Full\ wrong}\ \land\ \exists x:\mathrm{Mask}\ x\ \mathrm{correct}).
\]

**IG 与 CDNS 并非独立信号。** 当前 IG 的负分部分额外体现 Full 比至少一个 Mask 更差的情况。它是准确率差，不是香农互信息，不用 bit 为单位。

若将来每个条件重复作答，可估计逐样本成功概率，再计算概率版本的 IG；那是单独的扩展协议。当前程序明确采用一次作答，不接受通过重复请求 ID 偷渡的多次结果。

## 9. 手算例子：仅演示公式

假设四道双域问题都融合 X、Y：

| 样本 | Full | Mask X | Mask Y | CDNS | IG |
|---|---:|---:|---:|---:|---:|
| 1 | 1 | 0 | 0 | 1 | 1 |
| 2 | 1 | 1 | 0 | 0 | 0 |
| 3 | 0 | 0 | 1 | 0 | -1 |
| 4 | 1 | 0 | 1 | 0 | 0 |

则 CDNS=0.25，IG=0，DC_X=0.75−0.25=0.50，DC_Y=0.75−0.50=0.25。

例子中第 3 题 Full 错误仍参与 CDNS 分母。IG 先取每题最佳 Mask，四题最佳 Mask 为 0、1、1、1，均值为 0.75；不能改取两个领域平均 Mask 正确率的最大值 0.50。

## 10. No Domain、Only 和论文呈现

No Domain 准确率用于检查模型不看额外材料时能做对多少；Only x 准确率用于检查仅提供某个域的材料时能做对多少。两者是诊断，不能单凭高准确率证明模型内部只使用了某个领域。

建议论文呈现：

- 主表：按 k 和难度列样本总数、核心完整数、Full 准确率、CDNS、IG，以及 No Domain 准确率和它的有效分母。
- DC 热图：行是实际领域，列是 k 或 k×难度，颜色表示 DC；格内附配对样本数。不存在的领域显示 N/A，负贡献使用另一侧颜色。
- 条件准确率图：Full、各 Mask、No Domain、各 Only。诊断表中分母可能不同；直接作成因果差值时必须重新限制在同一配对集合，不能把不同分母的柱高机械相减。
- 案例矩阵：每行一题，列为 Full、Mask 各域、No Domain、Only 各域，显示正确/错误/缺失，再给 CDNS 与 IG。

当前汇总为样本等权的 micro 平均，同时导出 k、难度、源领域、k×难度分组。没有默默改成源领域等权 macro。跨领域数的主比较应优先使用分开的 k 组。

还应报告：模型及权重版本、材料选择、固定 Prompt、解码设置、错误/拒答数量。多选项题存在猜测命中；高 CDNS 是该协议下的行为证据，不自动构成严格不可解证明。
