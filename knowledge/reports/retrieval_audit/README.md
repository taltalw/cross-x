结论：暂时保留 rrf_k=60。当前抽查发现的主要问题是知识需求与领域题库不匹配、样本主题相关但不能提供所需知识；改变 RRF 常数不能补足缺失材料。尚无人工相关性标签，不能据排名变化断言某个参数精度更高。

## 具体问题

1. results_5.5/3_retrieve_knowledge/3_2_1_chemistry_domain_count_2.jsonl，第 1 行 medical：query 要求磷化氢吸入毒性和急救知识，前两条分别是百草枯、有机磷中毒题。它们不能直接作为磷化氢处理方法的证据。
2. 同文件第 2 行 legal：query 要求 OSHA/HAZWOPER 应急义务，第一条是劳动工时帖子是否属于住房问题的分类，答案 No，并未回答具体应急法规。
3. results_6 对应文件第 2 行 legal：query 要求 UK COSHH 条款，第一条是 Uber 合同的责任限制条款分类，适用知识不匹配。
4. 其他抽查有“B-tree 扇出/树高”命中真实树木高度题、“QSAR/分子对接预测”命中计算机 MFLOPS 题，说明词语或宽泛主题匹配不能等同于知识满足。

保存的训练语料全文关键词检查：medical 中 phosphine 为 0 条（paraquat 2 条、organophosphate 9 条）；legal 中 COSHH、HAZWOPER 均为 0 条，OSHA 为 12 条；computer_science 中 SMILES、cheminformatics、ADME 均为 0 条。没有出现某个术语不等于一定没有同义表述的知识，但结合候选内容，提示目前部分需求超出了题库覆盖。

## 为什么 k=60 影响不大

每个子列表只取 10 条。k=60 时，第 1 名贡献 1/61，第 10 名贡献 1/70，相差约 15%。多列表命中的次数往往比名次更影响排名。相似 query 会重复推高同一类材料；把 k 换为 20 依然保留这种倾向。RRF 分数不是正确率、覆盖概率或可以跨 query 直接比较的置信度。

## 建议顺序

1. 暂保留 60，不仅为了改变分数大小而调参。过滤会阅读全部 20 条；只改变前几名的排序不一定改善最终材料。
2. 先用 LLM 过滤区分真正提供知识和仅提到主题的候选，按领域统计 sufficient/partial/none，并人工检查少量保留与拒绝材料。
3. 对明显不适合题库的 query，保留本领域真正需要贡献的概念或方法，减少其他领域的背景词；不能删除构题必需的实体或适用条件后冒充命中。必要时回退融合思路或补充语料。
4. 有人工标注后再比较 k=10/20/60；同时可比较每路 top_k=10/30。关注 Recall@20、Precision@20 和最终可用材料率，不仅关注排名变化。
